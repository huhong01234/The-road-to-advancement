# 预编译
发生在代码执行前一刻

（v8引擎有一个编译部门和一个执行部门）

# 函数体内的预编译
1.创建一个执行上下文对象 AO：{}
2.找形参和变量声明，将形参和变量名作为AO的属性名，值为undefined
3.将形参和实参统一
4.在函数体内找函数声明，将函数名作为AO的属性名，值为函数体


# 全局的预编译
1.创建一个全局执行上下文对象 GO：{}
2.找全局变量声明，将全局变量名作为GO的属性名，值为undefined
3.找全局函数声明，将全局函数名作为GO的属性名，值为函数体


# V8的调用栈
-为什么需要调用栈？
1.代码执行前需要先编译，编译得到的上下文对象需要存储起来，方便后续执行
2.函数的执行顺序需要整理记录
