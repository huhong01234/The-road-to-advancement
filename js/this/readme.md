# this 是什么
- 是一个关键字，它提供了一种更优雅的方式传递一个对象的引用，可以让代码更简洁易懂


# this 可以出现在哪？
1. this 出现在全局，就指向 window 对象
2. 函数


# this的指向
1. 默认绑定规则--- 当函数独立调用时，this 指向 window 对象
2. 隐式绑定规则 ---当一个函数被一个对象所拥有，并被该对象调用时，函数中的this 指向该对象
3. 显示绑定规则--- fn.call(obj) 或 fn.apply(obj) 或 fn.bind(obj)(Z) 
4. new 绑定 --- 因为new的原理中存在显示绑定过程，所以导致函数被调用后，函数中的this 指向新创建的实例。
5. 箭头函数--箭头函数不存在this指针，写在函数体中的this ，也是它外层哪个非箭头函数的。 


# 原型的问题 
- 原型链：V8在查找对象中的属性时，会先查找对象显示拥有的属性，如果么有，就会顺着对象的隐式原型往上找，如果还找不到，就会顺着隐式原型往上找，直到找到 null 为止。
