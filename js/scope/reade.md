# 作用域
1. 全局作用域
2. 函数作用域
3. 块级作用域:let + {} 语句块 会形成一个块级作用域
4. 闭包作用域:函数内部的变量可以在函数外部访问


-作用域的访问规则
  - 从内到外，从上到下
  - 先局作用域的变量可以在任何作用域访问
  - 函数作用域的变量只能在函数内部访问
##词法作用域
  - 词法作用域是指在函数调用时，变量的作用域是根据函数的定义位置来确定的，而不是根据函数的调用位置来确定的。
#欺骗词法作用域
  - 欺骗词法作用域是指在函数调用时，变量的作用域是根据函数的调用位置来确定的，而不是根据函数的定义位置来确定的。
